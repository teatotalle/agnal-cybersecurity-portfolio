# Agnal Smith A — Cybersecurity Portfolio

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive cyber-style design
- `script.js` — typing animation, reveal animations, slide navigation and scroll progress
- `assets/agnal-profile.jpeg` — profile photo supplied by Agnal

## Before publishing
1. Replace the `#` links for GitHub, LinkedIn and CV in `index.html`.
2. Add GitHub/live-demo links for projects when available.
3. If you want a downloadable CV, place your PDF in the project folder and change the CV link to its filename.
4. Test the site on mobile and desktop.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish
See the ChatGPT instructions that accompanied this package for GitHub and Netlify deployment steps.
